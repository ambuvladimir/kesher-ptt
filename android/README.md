# אפליקציית אנדרואיד — יוסי אמבולנס

מכשיר קשר לשטח: מסך ראשי, PTT, GPS, חירום, צלילי תחילת/סיום שיחה ותקלה, עיצוב בהיר/כהה.

## בניית APK / אמולטור ב-Mac

1. Android Studio → Open → תיקיית `android/`.
2. Device Manager → Pixel (Apple Silicon: arm64).
3. Run.
4. כתובת שרת באמולטור: `http://10.0.2.2:8080`
   במכשיר אמיתי: `http://IP-של-המחשב:8080`

אחרי התחברות מגיעים **למסך הראשי**. משם נכנסים למכשיר הקשר, מחליפים ערכת נושא, או יוצאים.
