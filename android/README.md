# אפליקציית אנדרואיד — קשר PTT

אפליקציה מקורית (Kotlin) למכשירי שטח: כניסה לשרת הבית, בחירת ערוץ, PTT, GPS וחירום.

## בניית APK

1. התקינו [Android Studio](https://developer.android.com/studio).
2. File → Open → תיקיית `android/`.
3. חכו ל-Gradle Sync.
4. חברו טלפון עם USB debugging או בחרו אמולטור.
5. Run.

להפקת APK להתקנה ידנית: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## הגדרה במכשיר

- כתובת שרת: `http://192.168.x.x:8080` (ה-IP של שרת ה-Docker ברשת הבית)
- משתמש/סיסמה כמו במערכת הניהול
- אשרו הרשאות **מיקרופון** ו**מיקום**

האפליקציה מרשה HTTP פנימי (`usesCleartextTraffic`) כדי לעבוד ב-LAN בלי תעודת SSL.

## מה האפליקציה עושה

- מתחברת ב-Socket.IO לאותו פרוטוקול של ממשק הווב
- מקליטה PCM 16kHz ומשדרת כל עוד מחזיקים PTT
- משמיעה שידורים מהערוץ הנבחר
- שולחת מיקום GPS למוקד
- כפתור חירום

אין צורך ב-Google Play או ב-FCM. הכל מול השרת המקומי בלבד.
