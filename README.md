# יוסי אמבולנס — מערכת קשר

מערכת PTT ארגונית של **יוסי אמבולנס**: ערוצים, מוקד דיספאצר, ניהול משתמשים, מיקום GPS, צלילי קשר, ועיצוב בהיר/כהה. רצה בבית על Docker.

## מה כלול

- **מסך ראשי (דאשבורד)** מכל עמוד, עם לוגו ושם החברה
- **PTT חצי-דופלקס** עם צלצול נכנס ברור, צליל סיום, ושמע 24kHz חלק (jitter-buffer)
- **שיחות קבוצתיות** (ערוצי נהגים / מוקד / חירום) ו**שיחות אישיות** אחד-על-אחד
- **תפקידים**: מנהל מערכת, דיספאצר, נהג
- **מוקד דיספאצר**: מפה חיה, חיפוש כוחות, האזנה/דיבור
- **ניהול**: משתמשים, יחידות, הרשאות האזנה/דיבור, יומן
- **עיצוב בהיר** כברירת מחדל, עם מעבר לעיצוב כהה
- **אנדרואיד**: מסך ראשי, PTT, צלילים, בהיר/כהה

## ארכיטקטורה

```
טלפון אנדרואיד / דפדפן  ──HTTP+WebSocket──►  Nginx :8080
                                              ├─ UI (React)
                                              └─ API + Socket.IO :3000
                                                    └─ SQLite (volume)
```

השמע עובר כ-PCM 24kHz מונו (דיבור רחב-פס) דרך Socket.IO, עם jitter-buffer בצד הלקוח כדי שהשיחה תישאר חלקה. מתאים לרשת ביתית/LAN עם עשרות משתמשים, בלי תלות בענן. שיחה נכנסת משמיעה צלצול ברור לפני הדיבור.

## הרצה ב-Docker (מומלץ)

בשרת (מיני-PC, NAS, Raspberry Pi 64-bit, או מחשב ביתי):

```bash
cp .env.example .env
# ערכו JWT_SECRET לערך ארוך אקראי
docker compose up -d --build
```

פתחו בדפדפן: `http://IP-של-השרת:8080`

### חשבונות דמו (נוצרים אוטומטית בהפעלה ראשונה)

| משתמש | סיסמה | תפקיד |
|---|---|---|
| `admin` | `KesherAdmin!23` | מנהל מערכת |
| `dispatcher` / `dispatcher2` | `KesherDisp!23` | דיספאצר |
| `driver1` / `driver2` / `driver3` | `KesherField!23` | נהג אמבולנס |

**שנו את הסיסמאות מיד אחרי ההתקנה** במסך הניהול.

## גישה מהטלפונים ברשת הבית

1. ודאו שהשרת והטלפונים באותה רשת Wi‑Fi (או VPN ביתי).
2. במחשב השרת בדקו את ה-IP, למשל `192.168.1.10`.
3. פתחו `http://192.168.1.10:8080/radio` או השתמשו באפליקציית האנדרואיד.

### חשוב על מיקרופון בדפדפן

Chrome בטלפון דורש **HTTPS** כדי לאפשר מיקרופון, חוץ מ-`localhost`. לכן בשטח עדיף:

- אפליקציית האנדרואיד המקורית (עובדת עם HTTP ברשת הפנימית), או
- להעמיד HTTPS ביתי (Caddy/Nginx עם תעודה פנימית) מול פורט 8080.

במחשב המוקד בדפדפן מקומי המיקרופון עובד גם ב-HTTP על localhost.

## אפליקציית אנדרואיד

1. פתחו את התיקייה `android/` ב-Android Studio.
2. Sync + Run למכשיר.
3. במסך הכניסה הזינו `http://IP-של-השרת:8080`, משתמש וסיסמה.
4. החזיקו את כפתור **PTT** כדי לדבר.

פירוט נוסף: [`android/README.md`](android/README.md)

## תפקידים והרשאות

| תפקיד | מה רואה |
|---|---|
| מנהל מערכת | הכל: משתמשים, ערוצים, יומן, מפה, PTT |
| דיספאצר | מפה, כל הערוצים, כוחות, שיחות קבוצתיות ואישיות |
| נהג | מכשיר קשר, ערוצים קבוצתיים, שיחות אישיות אחד-על-אחד |

במכשיר הקשר: **שיחה קבוצתית** (ערוץ) או **שיחה אישית** (בחירת אדם). במוקד, כפתור «אישי» ליד כל כוח.

## ערוצים שנזרעים בהתחלה

- מוקד ראשי (`DISP-1`) — קבוצתי למוקד
- נהגים (`TG-DRIVERS`) — קבוצתי לנהגים
- חירום (`EMRG`)
- שידור כללי (`ALLCALL`)
- שיחות אישיות נוצרות אוטומטית בלחיצה על איש קשר

כפתור **חירום** בנייד מסמן את המשתמש במפה ומשדר התראה לכל המוקד.

## אבטחה בבית

- שנו `JWT_SECRET` וסיסמאות ברירת מחדל
- אל תפתחו את פורט 8080 לאינטרנט בלי VPN (WireGuard/Tailscale מומלץ)
- הנתונים נשמרים ב-volume של Docker בשם `kesher-data` (SQLite)

גיבוי:

```bash
docker compose exec api sh -c "cp /data/kesher.db /data/kesher-backup-$(date +%F).db"
```

העתק הקובץ מתוך ה-volume, או גבו את כל Docker volume.

## פתרון תקלות

- **אין שמע מהדפדפן**: אשרו מיקרופון; במובייל עברו לאפליקציה או HTTPS
- **טלפון לא מתחבר**: בדקו IP, פיירוול של השרת (`8080/tcp`), ושהמכשיר ב-LAN
- **מפה ריקה**: OSM דורש יציאה לאינטרנט לתמונות המפה. המיקומים עצמם מקומיים
- **איפוס דמו**: מחקו את ה-volume `docker compose down -v && docker compose up -d --build`
