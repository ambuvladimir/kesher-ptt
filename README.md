# קשר — מערכת PTT ארגונית לשרת ביתי

מערכת קשר פנימית (Push-to-Talk) שרצה אצלכם בבית על Docker: ערוצים, מוקד דיספאצר עם מפה חיה, ניהול משתמשים/הרשאות, ומיקום GPS. כוללת ממשק ווב (כולל מכשיר קשר למובייל) ואפליקציית אנדרואיד מקורית.

## מה כלול

- **PTT חצי-דופלקס** — דובר אחד בכל ערוץ, עם "תפוס ערוץ" (floor control) ומגבלת זמן דיבור
- **ערוצים**: קבוצות דיבור, מוקד, שידור כללי, חירום
- **מוקד דיספאצר**: מפה חיה, רשימת כוחות, האזנה/דיבור לכל ערוץ, התראות חירום
- **ניהול**: משתמשים, יחידות, הרשאות האזנה/דיבור לכל ערוץ, יומן ביקורת
- **מיקום**: עדכון GPS מהשטח אל המוקד
- **אנדרואיד**: כפתור PTT, ערוצים, חירום, מיקום ברקע
- **פריסה מקומית**: `docker compose up` על שרת הבית

## ארכיטקטורה

```
טלפון אנדרואיד / דפדפן  ──HTTP+WebSocket──►  Nginx :8080
                                              ├─ UI (React)
                                              └─ API + Socket.IO :3000
                                                    └─ SQLite (volume)
```

השמע עובר כ-PCM 16kHz מונו דרך Socket.IO. זה מתאים לרשת ביתית/LAN עם עשרות משתמשים, בלי תלות בענן.

## הרצה ב-Docker (מומלץ)

בשרת (מיני-PC, NAS, Raspberry Pi 64-bit, או מחשב ביתי):

```bash
cp .env.example .env
# ערכו JWT_SECRET לערך ארוך אקראי
docker compose up -d --build
```

פתחו בדפדפן: `http://IP-של-השרת:8080`

### חשבונות דמו (נוצרים אוטומטית בהפעלה ראשונה)

| משתמש | סיסמה | תפקיד |
|---|---|---|
| `admin` | `KesherAdmin!23` | ניהול מלא |
| `dispatcher` | `KesherDisp!23` | מוקד דיספאצר |
| `supervisor` | `KesherSup!23` | אחמ״ש סיור |
| `siur1` / `siur2` | `KesherField!23` | ניידות שטח |
| `sec1` | `KesherField!23` | אבטחה |
| `tech1` | `KesherField!23` | תחזוקה |

**שנו את הסיסמאות מיד אחרי ההתקנה** במסך הניהול.

## גישה מהטלפונים ברשת הבית

1. ודאו שהשרת והטלפונים באותה רשת Wi‑Fi (או VPN ביתי).
2. במחשב השרת בדקו את ה-IP, למשל `192.168.1.10`.
3. פתחו `http://192.168.1.10:8080/radio` או השתמשו באפליקציית האנדרואיד.

### חשוב על מיקרופון בדפדפן

Chrome בטלפון דורש **HTTPS** כדי לאפשר מיקרופון, חוץ מ-`localhost`. לכן בשטח עדיף:

- אפליקציית האנדרואיד המקורית (עובדת עם HTTP ברשת הפנימית), או
- להעמיד HTTPS ביתי (Caddy/Nginx עם תעודה פנימית) מול פורט 8080.

במחשב המוקד בדפדפן מקומי המיקרופון עובד גם ב-HTTP על localhost.

## אפליקציית אנדרואיד

1. פתחו את התיקייה `android/` ב-Android Studio.
2. Sync + Run למכשיר.
3. במסך הכניסה הזינו `http://IP-של-השרת:8080`, משתמש וסיסמה.
4. החזיקו את כפתור **PTT** כדי לדבר.

## תפקידים והרשאות

| תפקיד | מה רואה |
|---|---|
| מנהל | הכל: משתמשים, ערוצים, יומן, מפה, PTT |
| דיספאצר | מפה, כל הערוצים, כוחות, חירום — בלי מחיקת משתמשים |
| אחמ״ש | מפה וכוחות של היחידה שלו |
| שטח | מכשיר קשר, ערוצים ששויכו, מיקום של עצמו |

לכל משתמש אפשר לסמן לכל ערוץ: **האזנה**, **דיבור**, **ערוץ ראשי**.

## ערוצים שנזרעים בהתחלה

- מוקד ראשי (`DISP-1`)
- סיור 1 (`TG-SIUR-1`)
- אבטחה (`TG-SEC`)
- תחזוקה (`TG-TECH`)
- חירום (`EMRG`) — כולם מאזינים
- שידור כללי (`ALLCALL`) — דיבור בעיקר למוקד/מנהל

כפתור **חירום** בנייד מסמן את המשתמש במפה ומשדר התראה לכל המוקד.

## אבטחה בבית

- שנו `JWT_SECRET` וסיסמאות ברירת מחדל
- אל תפתחו את פורט 8080 לאינטרנט בלי VPN (WireGuard/Tailscale מומלץ)
- הנתונים נשמרים ב-volume של Docker בשם `kesher-data` (SQLite)

גיבוי:

```bash
docker compose exec api sh -c "cp /data/kesher.db /data/kesher-backup-$(date +%F).db"
```

העתק הקובץ מתוך ה-volume, או גבו את כל Docker volume.

## פתרון תקלות

- **אין שמע מהדפדפן**: אשרו מיקרופון; במובייל עברו לאפליקציה או HTTPS
- **טלפון לא מתחבר**: בדקו IP, פיירוול של השרת (`8080/tcp`), ושהמכשיר ב-LAN
- **מפה ריקה**: OSM דורש יציאה לאינטרנט לתמונות המפה. המיקומים עצמם מקומיים
- **איפוס דמו**: מחקו את ה-volume `docker compose down -v && docker compose up -d --build`
